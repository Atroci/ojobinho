# Como contribuir

Ao participar, siga o [Código de Conduta](CODE_OF_CONDUCT.md).

1. Abra uma issue descrevendo problema brasileiro concreto.
2. Crie branch curta e mudança focada.
3. Não adicione dados pessoais, vagas privadas ou credenciais.
4. Execute `npm test`, `npm run init` e `npm run doctor` antes do pull request.
5. Explique por que a mudança ajuda candidatos e quais limites preserva.

Contribuições devem manter revisão humana antes de qualquer candidatura. Relatos de vulnerabilidade seguem [SECURITY.md](SECURITY.md), nunca issue pública.
