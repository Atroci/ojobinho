# Contexto

oJobinho é um produto público PT-BR para organizar busca de emprego com agentes de IA. Dados ficam locais; envio externo depende sempre do candidato.

Primeiro recorte comunitário: vagas remotas de Design, Branding e Social no Brasil e na América Latina, via planilha pública mantida com apoio da UNEIA. SelfProxy apoia testes autorizados de páginas públicas em redes móveis reais; não integra o fluxo de candidatura.
