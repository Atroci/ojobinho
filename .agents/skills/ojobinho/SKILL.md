# oJobinho

Leia `AGENTS.md` e aplique o modo correspondente:

- URL ou descrição de vaga: `modes/avaliar.md`
- Pedido para preparar candidatura: `modes/aplicar.md`
- Pedido por oportunidades: mostre `npm run vagas` e ajude a escolher uma linha da planilha.
- Busca por cargo ou local: execute `npm run buscar -- "termo"`.
- Dúvida sobre um portal: execute `npm run portal -- "URL"` e entregue o handoff manual.

Toda candidatura termina em revisão humana. Nunca envie formulários, mensagens ou e-mails.
