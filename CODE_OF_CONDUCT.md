# Código de Conduta

## Nosso compromisso

Queremos uma comunidade aberta, segura e útil para pessoas buscando trabalho no Brasil. Participantes devem agir com respeito, independentemente de origem, aparência, identidade, experiência, condição econômica, deficiência, religião ou opinião.

## Comportamento esperado

- acolher dúvidas e contribuições com respeito;
- criticar ideias, nunca pessoas;
- preservar dados pessoais de candidatos e recrutadores;
- aceitar correções e assumir responsabilidade por erros;
- manter discussões relacionadas ao projeto.

Não aceitamos assédio, discriminação, ameaça, exposição de dados pessoais, conteúdo sexualizado, fraude, spam ou uso do projeto para explorar candidatos.

## Aplicação

Moderadores podem editar ou remover conteúdo e restringir participação quando necessário. Para relatar conduta inadequada, use os canais privados disponíveis no perfil da organização [Atroci](https://github.com/Atroci). Não inclua dados sensíveis além do mínimo necessário.

Relatos serão avaliados de forma reservada e proporcional. Retaliação contra quem relata um problema de boa-fé não será aceita.

## Escopo

Este código vale nos espaços do projeto e quando alguém representa publicamente o oJobinho.
